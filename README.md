# Defining-emotional-intelligence-integration-of-logic-emotion-and-long-term-consequence-awareness
Research repository for “Defining Emotional Intelligence: Integration of Logic, Emotion, and Long-Term Consequence Awareness” by Megha Monga. Proposes EI as an integrated emotional output of logic, emotion, and long-term consequence awareness within a three-layer cognitive architecture.
